## Основные проекты

### Walmart Sales Analysis
Проект по анализу данных и машинному обучению на основе данных о продажах Walmart.

Что реализовано:
- очистка и подготовка данных;
- разведочный анализ данных (EDA);
- создание новых признаков;
- проверка статистических гипотез;
- интерактивное веб-приложение на Streamlit.

### CaseBridge

Проект по сравнению и оценке моделей машинного обучения для задачи классификации. Цель проекта — определить наиболее эффективную модель на основе объективных метрик качества и анализа результатов.

В рамках проекта были выполнены:

- предварительная обработка и подготовка данных;
- исследовательский анализ данных (EDA);
- кодирование категориальных признаков и обработка пропусков;
- обучение нескольких моделей машинного обучения;
- подбор гиперпараметров;
- сравнение моделей по ключевым метрикам качества;
- анализ важности признаков (Feature Importance);
- визуализация результатов и интерпретация моделей.

### Используемые технологии

- Python
- Pandas

### Результат

Проведено сравнение нескольких алгоритмов машинного обучения, определена наиболее эффективная модель и выполнен анализ факторов, оказывающих наибольшее влияние на качество предсказаний.
